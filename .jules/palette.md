## 2024-05-14 - Add title to clear search button in LeftSidebar
**Learning:** Icon-only buttons used for clearing inputs should have both `aria-label` for screen readers and `title` for mouse users to provide better context and accessibility.
**Action:** When creating or modifying icon-only buttons, especially those that appear dynamically like a clear search button, ensure both `aria-label` and `title` are present if a tooltip is desired.
