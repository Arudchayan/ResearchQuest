## 2024-05-03 - Mitigate Timing Attacks in API Key Validation
**Vulnerability:** The `create-admin-user` Supabase Edge Function compared the incoming `ADMIN_API_KEY` header against the expected environment variable using standard strict equality (`!==`). This allows an attacker to brute-force the API key character-by-character by measuring the time it takes for the function to respond (a timing attack).
**Learning:** Standard string comparisons terminate early upon finding the first mismatched character. In security contexts (like passwords or API keys), this exposes the length of the matching prefix. `node:crypto` or `crypto.subtle` are not reliably available or easily synchronous in all Edge Function runtimes (like Deno).
**Prevention:** Always use constant-time comparison algorithms for secret verification. When native timing-safe comparison methods are unavailable, implement a robust custom function using bitwise XOR operations (`^`) on character codes that evaluates the full length of the strings regardless of where mismatches occur.
